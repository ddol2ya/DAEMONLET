# Daemonlet for Codex

Windows 압축판은 폴더 전체를 풀고 `Daemonlet for Codex/Daemonlet for Codex.exe`를 실행합니다. 같은 계정의 Codex Desktop과 Hook 없이 자동 연결됩니다. 설치형은 Setup.exe로 설치한 뒤 시작 메뉴에서 실행합니다.
Mac은 `.app`을 응용 프로그램 폴더로 옮긴 뒤 설정 → Codex 연결 → 연결 준비에서 Hook을 설정하고 Codex에서 실행을 허용합니다.

기본 캐릭터는 지피쨩 하나입니다. 추가 `.petchar`는 앱 설정에서 가져옵니다. 이 앱에는 제작 스킬·ComfyUI·모델 가중치가 포함되지 않으며, 사용에 제작용 GPU가 필요하지 않습니다.

서명·공증 여부는 내려받은 릴리스 설명을 확인하세요. Windows/Linux 앱 폴더의 `resources/licenses/`, macOS 앱 패키지의 `Contents/Resources/licenses/`에서 코드·라이브러리 전문 및 `ARTWORK-NOTICE.md`, `ARTWORK-LICENSE.md`, `ARTWORK-SCOPE.json`, `CC-BY-4.0.txt`를 읽을 수 있습니다. 지피쨩 파일에서 제공자가 허락할 수 있는 프로젝트 추가 기여와 별도 승인 아이콘에는 CC BY 4.0을 적용하며, 그 범위에서 출처·라이선스·변경 표시 조건으로 수정·재배포·상업적 이용을 허용합니다. 참고한 커뮤니티 디자인·이미지·시트의 이용 조건은 미확인이고 이 허락에 포함되지 않으므로, 이미지 전체의 재사용 권한을 보장하는 표기가 아닙니다. 확인 가능한 모음글과 출처 정정은 ARTWORK-NOTICE.md에 있습니다.
