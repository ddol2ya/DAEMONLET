# v0.8.5

Windows 로컬챗과 GGUF 음성에서 GPU 실행 방식을 자동으로 선택할 수 있습니다.

- Windows 설치 프로그램과 ZIP 각각에 CUDA·Vulkan 로컬챗 실행기를 함께 포함합니다. 설정에서 `자동 / CUDA / Vulkan`을 선택하고 실제 선택된 GPU를 확인합니다.
- 자동 로컬챗은 CUDA를 우선 확인하고, 장치가 없거나 모델 초기화가 실패하면 소유한 프로세스를 정리한 뒤 Vulkan을 시도합니다. 수동 선택과 중단 요청은 그대로 따릅니다.
- Qwen·Vox GGUF 음성은 대화와 별도로 실행 방식을 선택합니다. 자동 파일 준비는 두 실행 환경을 준비하며 모델 파일은 공유합니다. CUDA 초기화 실패 시 이미 연결된 Vulkan 실행기로 전환합니다. 발화 중 임의로 파일을 다운로드하지 않습니다.
- GGUF CUDA 음성의 compute capability 8.9 고정 제한을 제거합니다. CUDA 13 드라이버 API, 파일 SHA-256, 실제 GPU 모델 로딩 검사는 유지합니다. Vulkan에는 CUDA 드라이버 조건이 적용되지 않습니다.
- 기존 대화, 수동 실행 방식, 기본 음성·학습팩별 연결, WAV 기준 음성과 외부 모델을 보존합니다. Mac Metal·MLX 경로는 유지합니다.

Windows 실기 검증 장치는 RTX 4090 24GB와 드라이버 610.47입니다. E4B·12B의 CUDA·Vulkan 연속 대화, 스트리밍 중단 및 복구를 검증했습니다. AMD·Intel·RTX 50 시리즈의 실기 검증이나 최소 VRAM 보장은 포함하지 않습니다. CUDA 실행 파일에는 PTX가 포함되어 있지만 이는 모든 GPU의 실행 성공을 보장하지 않습니다.

최종 설치본·서명·공증·업데이트 파일의 검증 결과와 해시는 공개 릴리즈의 검증 기록 및 `SOURCE-PROVENANCE.json`, `SHA256SUMS.txt`에 따릅니다. Windows는 기존 미서명 배포 정책을 유지합니다. 원본 소스·라이선스와 변경 없는 libsndfile/codec 런타임 재빌드 소스를 함께 제공합니다.
