# Apple Silicon Mac

릴리스 ZIP을 압축 해제하고 `Daemonlet for Codex.app`을 응용 프로그램 폴더로 옮깁니다. 다음 두 연결 경로를 구분하세요. 아래의 데스크톱 연결은 앱 안의 **Codex 작업**을 대상으로 합니다.

**데스크톱 앱에서 Codex 작업을 사용하는 경우:**

1. 같은 macOS 계정에서 데스크톱 앱과 Daemonlet을 실행합니다. 첫 실행의 Hook 안내는 **나중에**로 넘길 수 있습니다.
2. 캐릭터의 우클릭 메뉴에서 **Codex 제어 · 음성 입력**을 열고 **제어할 대화**에서 Codex 작업을 선택합니다.
3. 데스크톱 자동 연결 상태를 확인합니다. 이 직접 연결의 전송·중지는 Hook 설치나 CLI의 `/hooks` 승인을 필요로 하지 않습니다. 작업 실행에 대한 승인 요청은 해당 Codex 작업에서 확인합니다.

**Codex CLI 작업 이벤트도 받으려는 경우:**

Codex CLI만 단독으로 사용하면 Daemonlet이 정상 작동하지 않을 수 있습니다. Codex 데스크톱 앱을 함께 실행해 주세요.

1. **설정 → Codex 연결 → CLI Hook 설정**을 누릅니다. 이미 설치했다면 버튼은 **Hook 확인**으로 표시됩니다.
2. Hook 설치 또는 수리 미리보기의 대상 폴더와 명령을 확인한 뒤 **변경을 확인했으며 적용**을 누릅니다.
3. 같은 Codex 설정 폴더를 사용하는 CLI에서 `/hooks`를 열어 정확한 Hook 정의를 검토하고 신뢰합니다. Daemonlet의 **Codex에서 검토했어요**는 실제 신뢰를 대신하는 버튼이 아니라 검토 완료를 기록하는 버튼입니다.
4. CLI에서 작업을 실행한 뒤 Daemonlet의 이벤트 수신을 확인합니다.

CLI용 Hook을 설치했다면 앱 경로를 변경할 때 수리가 필요할 수 있으므로 설치 위치를 먼저 정하세요. 이미 다른 앱의 Hook을 사용 중이면 충돌 안내를 확인하고 임의로 기존 항목을 삭제하지 마세요. 별도 검증용 Codex 설정 폴더에서 한 승인이 일반 설정 폴더에도 적용됐다고 가정하지 않습니다.

Developer ID 서명·Apple 공증 여부는 해당 릴리스 설명을 확인합니다. 직접 빌드한 앱에는 자동 적용되지 않습니다. 이전 이름의 앱에 받은 공증도 새 바이너리에 승계되지 않습니다.

기본 캐릭터는 지피쨩 하나입니다. 추가 `.petchar`는 설정에서 가져옵니다. 데이터는 `~/Library/Application Support/Daemonlet for Codex`에 저장하며 기존 2D Live/Test 데이터는 가져오지 않습니다.
앱 사용에는 별도 Python, ComfyUI, 모델 또는 NVIDIA GPU가 필요하지 않습니다.


## 연결 복구와 제거

PR #17의 **캐릭터 대화** 후보는 일반 메뉴에서 연결 준비·공식 CLI 선택·다시 확인을 제공합니다.
새 설치는 ON, 기존 OFF는 유지하며 보내기 전에는 모델을 생성하지 않습니다.
공식 CLI 0.154.0 Apple Silicon 경로의 [지원 범위와 로그인·복구 안내](side-chat.md)를 확인하세요.
이 설명은 기존 공개 v0.7.1 다운로드의 기능이나 새 후보의 서명·공증 완료를 뜻하지 않습니다.
별도 프로필이 필요하면 `DAEMONLET_DATA_HOME`을 지정할 수 있으며 기존 앱 데이터는 이전하지 않습니다.

- 데스크톱 직접 연결이 끊기면 데스크톱 앱 실행 상태와 **Codex 제어**의 새로고침·선택한 작업을 확인합니다.
- CLI용 Hook을 설치한 뒤 앱을 이동했거나 Codex 업데이트 후 연결이 끊기면 **설정 → Codex 연결 → 새로 확인 / CLI Hook 설정(설치 후 Hook 확인)**를 실행합니다. 고급 설정에서 Codex 실행 파일·데이터 폴더를 확인하고 **수리 미리보기**를 검토·적용합니다. Codex에서 이 앱의 변경된 Hook 실행 허용도 다시 확인합니다.
- 파일 권한·정책으로 막히면 표시된 원인을 확인합니다. 다른 앱 Hook 삭제나 시스템 보안 전체 비활성화를 복구 방법으로 사용하지 않습니다. 음성 입력 권한 거부 시 받아쓰기가 중단되며, 원하면 시스템 설정에서 마이크·음성 인식 권한을 확인할 수 있습니다.
- 캐릭터가 안 보이면 트레이 메뉴 **Show Pet**, **Reset Position**을 사용합니다. macOS Dock에서 앱을 다시 활성화해도 표시를 복구할 수 있습니다. 트레이 **Click-through → Disabled**를 선택하고, 설정에서 기본 지피쨩·크기·위치를 확인합니다.
- CLI용 Hook을 설치했다면 제거 전 **설정 → Codex 연결 → 고급 설정 → 연동 제거**를 열어 미리보기를 확인하고 적용합니다. 이 앱 소유의 Hook 변경만 제거하며 다른 Hook·Codex 설정과 앱 데이터는 보존합니다. 이미 앱을 삭제했다면 같은 앱을 다시 설치해 기존 Codex Home을 선택하고 제거 절차를 진행하세요.
- 이후 트레이 **Quit**으로 종료하고 응용 프로그램 폴더의 앱을 휴지통으로 옮깁니다. 필요한 경우에만 추가 팩을 백업한 뒤 이 앱의 사용자 데이터 폴더를 삭제합니다. 앱 파일만 삭제하면 Hook이 남을 수 있습니다.
