# 캐릭터 대화 / Character chat

캐릭터 대화는 v0.7.2부터 포함됩니다. 플랫폼별 검증 범위는 아래 호환성 표를,
배포 파일과 서명·공증 상태는 [릴리즈 안내](https://github.com/ddol2ya/DAEMONLET/releases/tag/v0.7.2)를
확인하세요. 개발자용 구조와 명령은 [개발 안내](side-chat-development.md)에 있습니다.

## 시작하기

1. 공식 [Codex CLI](https://developers.openai.com/codex/cli)를 설치하고
   [ChatGPT 로그인](https://developers.openai.com/codex/auth)을 완료합니다.
2. 기존 작업 말풍선의 **캐릭터에게 물어보기**를 누르면 그 작업을 맥락으로 같은 창에
   입력과 답변이 표시됩니다. 캐릭터 우클릭·트레이의 **캐릭터와 대화**도 같은 작업창을 엽니다.
   새 설치는 기본 ON이며, 이전 OFF는 **대화 설정 → 캐릭터 대화 사용**에서 직접 켭니다.
3. 연결에 문제가 있으면 **대화 설정 → 연결 준비**를 펼칩니다. 필요하면 **감지한 공식 CLI 사용** 또는
   **CLI 파일 선택**을 누릅니다. 이 선택은 사이드챗 전용이며 기존 작업 제어·Hook
   연결 설정을 변경하지 않습니다. 앱은 CLI를 설치·교체하거나 Codex 설정을 수정하지 않습니다.
   새 CLI 버전의 최초 연결에는 공식 파일 대조를 위한 인터넷 연결과 다운로드가 필요합니다.
   검증 결과는 앱 실행 중 메모리에 보관되므로 앱 재시작 후 다시 검증할 수 있습니다.
4. 작업창 제목에서 질문할 맥락을 확인합니다. 다른 작업은 작업 화살표 또는
   **대화 설정 → 다른 작업 찾기**에서 제목/ID로 선택합니다. 자동으로 다른 부모로 전환하지 않습니다.
   로컬 대화 연결 정보가 없는 작업은 이 창에서 맥락을 직접 선택해야 합니다.
   목록 갱신은 현재 대화와 초안을 유지합니다.
5. 질문을 작성합니다. 필요하면 해당 프로젝트의 파일과 줄 범위를 선택합니다.
   파일명·범위·읽은 시각을 확인하고 개별 제거할 수 있습니다.
6. 첫 **보내기**에서 맥락·선택 파일 전달, 사용량, 보관 및 권한에 동의합니다.
   취소하면 초안은 그대로 남습니다. 동의하면 같은 질문을 이어서 전송합니다.

메뉴 열기와 준비 확인은 CLI·인증·모델 catalog/사용량 등의 메타데이터를 조회할 수
있지만 모델 질문이나 fork를 만들지 않습니다. 동의 기록은 설정 ON/OFF와 별도로
저장합니다. 질문 전송은 매번 사용자의 보내기 동작으로만 시작됩니다.

## 대화·파일·권한

성공 완료된 턴까지 공식 fork한 별도 임시 자식만 사용합니다. 부모를 재개·중지·전송·승인·
삭제하지 않습니다. **맥락 기준 시점** 이후 부모의 변경은 자동 반영되지 않으며, 현재 작업
상태는 기존 관측기의 별도 시각을 표시합니다. 확인할 수 없으면 상태 미확인입니다.

자식은 맥락과 선택한 파일을 설명하고 복사할 수정안을 제시합니다. 파일 변경, 범용 명령,
빌드·테스트, 앱/외부 서비스 조작과 부모 제어는 허용하지 않습니다. 파일 조회는 Main의
선택형 읽기 경로로만 합니다. 자동 탐색이나 모델 shell은 없습니다.

파일은 선택 당시의 스냅샷입니다. 다시 읽어 몰래 교체하지 않습니다. 한 파일 1 MiB,
한 발췌 400줄/32 KiB, 한 전송 8파일/128 KiB까지입니다. 프로젝트 밖 경로, 링크,
비밀파일, 허용하지 않는 형식은 차단합니다. 일반 소스에 포함된 모든 비밀을 탐지한다는
보장은 없으므로 선택 내용을 확인하세요. 이미 부모 맥락에 있는 정보는 이 필터로 제거되지 않습니다.

긴 답변 펼치기는 같은 작업창을 확장합니다. 펼치기·복사·숨기기는 같은 원문을 사용하며
추가 모델 호출을 만들지 않습니다. 대화를 숨기면 기존 작업 알림으로 돌아갑니다.
HTML·스크립트·원격 이미지는 실행/로드하지 않습니다. 앱 대화·초안은 메모리에 있으며
앱 종료 시 사라집니다. Codex의 정상 내부 인덱스·캐시·로그·인증 처리는 발생할 수 있습니다.
[개인정보 안내](../PRIVACY.md)를 참고하세요. AI 표정 연출은 제공하지 않습니다.

## 연결 복구

| 표시 | 조치 |
| --- | --- |
| 꺼짐 | 저장한 OFF 선택입니다. 원할 때 **캐릭터 대화 사용**을 누릅니다. |
| CLI 없음/미지원 | 공식 설치와 버전을 확인하고 **CLI 파일 선택**, **다시 확인**을 누릅니다. |
| 로그인 필요/조회 불가 | 공식 CLI에서 로그인과 credential store 접근을 확인합니다. 앱은 로그인·로그아웃·계정 전환을 자동 실행하지 않습니다. |
| workspace 식별 확인 불가 | 공식 계정 메타데이터를 확인하지 못했습니다. 네트워크/저장소 접근을 확인합니다. 이메일만으로 계정을 추정하지 않습니다. |
| 모델 불가 | 계정의 모델 접근과 앱의 지원 안내를 확인합니다. 다른 모델·제공자로 자동 전환하지 않습니다. |
| 정책 충돌 | 조직 정책을 유지합니다. 현재 실행 제한을 적용할 수 있는지 관리자와 확인합니다. |
| 부모 미선택 | 맥락으로 사용할 대화를 선택합니다. |
| 성공 완료 턴 없음 | 부모가 성공 완료될 때까지 기다리거나 다른 완료 대화를 선택합니다. |
| 조회 한도/접근 문제 | 다른 대화를 선택하거나 원본 경로·삭제·접근 권한을 확인합니다. |
| 사용량/요청 한도·네트워크 | 계정 사용량 또는 연결을 확인한 뒤 수동으로 재시도합니다. |
| 연결 종료/계정 변경 | **새 대화**로 복구합니다. 초안은 보존하며 이전 첨부 권한은 재사용하지 않습니다. |
| 결과 불명 | 자동 재전송하지 않습니다. 중복 가능성을 확인한 뒤 새 대화에서 수동으로 보냅니다. |

## 호환성 범위

| 항목 | 현재 범위 |
| --- | --- |
| 공식 CLI | **0.154.0 이상**의 macOS arm64·Windows x64 공식 npm 설치본. 새 버전은 첫 연결 때 npm 공식 아카이브 무결성과 설치 파일 바이트를 대조한 뒤 실행. 이미 검토한 0.154.0 해시는 오프라인 확인 가능. |
| macOS | macOS 27 Apple Silicon에서 직접 검증. 최소 OS·다중 OS 사용자·다중 모니터 실측은 후보 보고서의 NOT_RUN을 확인. |
| Windows x64 | 공식 0.154.0 x64에서 같은 home의 인증·권한·모델 목록, 선택한 실제 부모의 fork와 첫/후속 답변을 직접 검증. 설정·Hook·부모 완료 경계 보존 확인. file 인증 기준이며 credential store별 미실행 항목은 후보 보고서에 구분. |
| 모델 | 현재 검증 후보는 `gpt-5.6-luna`, 낮은 추론 설정 하나. 계정 catalog와 교집합을 확인하며 대화 중 변경하지 않음. |
| file 인증 | 실제 계정의 준비 검증. 보호된 account ID를 확인하며 토큰 복사·주입 없음. |
| keyring/auto | 공식 사용량 응답의 검증된 workspace ID가 필요한 조건부 구현. 매 전송 전 새 제한 프로세스로 현재 인증을 조회. 실제 OS credential store 시험은 후보 보고서에서 별도 표시. 잠김/미로그인을 구분할 정보가 없는 응답은 조회 불가로 안내. |
| 관리 환경 | 강제 로그인 규칙이나 검증하지 않은 startup layer는 실행 전에 차단. 조직 통제 우회/제거 없음. |
| 이전/새 CLI | 0.154.0 미만은 차단. 새 버전도 권한·계정·API 계약 검사 필수이며, 호환되지 않으면 연결 차단. 신규 단독 바이너리는 버전 식별용 npm 메타데이터가 없어 공식 npm 설치본을 선택해야 함. 자동 업데이트·다운그레이드·custom fallback 없음. |

배포 후보의 직접 검증, 과거 실계정 답변, 미실행 항목 및 서명 상태는 PR에 분리해서
기록합니다. 코드 또는 단위 시험만으로 Windows/Keychain의 실제 지원을 주장하지 않습니다.

## 별도 앱 프로필과 복원

`DAEMONLET_DATA_HOME`에 별도 앱 데이터 폴더를 지정하면 기존 설정·팩을 건드리지 않고
독립된 프로필로 실행할 수 있습니다. 이는 CLI home이나 모델 제공자를 바꾸지 않습니다.
일반 실행에서는 OS의 기존 Daemonlet 사용자 데이터 폴더를 그대로 사용합니다.
앱 파일만 교체/제거하면 사용자 팩과 설정은 남습니다. 복원 시 해당 프로필을 유지하고
기존 앱 버전을 실행하세요. Codex 원본 세션이나 시스템 custom CLI는 정리 대상이 아닙니다.
